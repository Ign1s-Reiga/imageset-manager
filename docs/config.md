# Config

This application can configuration by editing `ism.config.json` or editing on webpage.

## Config params

| Param Name              | Description                                 |
|-------------------------|---------------------------------------------|
| `imagesetPath`          | `imagesets` dirPath. Put absolutely Path.   |
| `maxSaveRecentViewed`   | amount of recent viewed imagesets history   |
| `maxSaveRecentUploaded` | amount of recent uploaded imagesets history |

# Imageset Manager

## What is Imageset Manager?

Imageset Manager is a tool for managing imagesets.
It is a web application that allows you to upload images and organize them into sets.
You can tag them, and search them by tags.

## Features

* Upload images, as simple operation.
* Search ImageSet by words or tags,
* Add some info to Imageset(category tags, authors, etc.).
* And more...

## Requirements

* Node.js (Recommend LTS version)
* MongoDB Server

## Installation

1. Clone or download this repository.
2. Install dependencies.

```bash
    # If you are using npm
    $ npm install

    # Also if you are using yarn
    $ yarn install
```

3. Create `.env.local` file.

## Usage

### Upload images

Image extension that I recommend `.webp` or `.avif`.
